# Part 1 - BASE case, complete fields

Generated by `code/catalog/catalog_fields_R1.m` (R1, 2026-11-14). Colour figures, each saved as .png and .fig.

Fields are rebuilt from the stored campaign states (`LSTE_fields_R1`); the rebuild reproduces the solver's own Srr/Stt/Szz at z=L/2 to 1.4e-11 (`LSTE_fields_R1_check`).

Dimensionless forms: U* = u/((1-nu)aT h), W* = w/((1-nu)aT L), eps* = eps/(aT) (also the engineering shear gamma_rz), Sigma = (1+nu)sigma/(E a T), with E, nu, a, T = 4.433e9, 0.3395, 5.9814e-5, 300 (as catalog_R18_color); xi = (r-Ri)/(Ro-Ri), z/L, Fo = ahat t/h^2.

Locations: u, eps_rr, eps_tt, eps_zz, Sigma_rr, Sigma_tt, Sigma_zz at z = L/2; w, gamma_rz, Sigma_rz at the node nearest z = L/4 (z = 0.206 L), stated in the y-label. Axial profiles at xi = 0.5. Profiles at the final time of each case.
